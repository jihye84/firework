# 불꽃 연출 디자이너

유튜브 음악에 맞춰 한강 불꽃놀이를 직접 연출해 보는 웹앱입니다.
2025 서울세계불꽃축제(여의도)의 연출 방식을 참고해,
불꽃의 색·모양·크기·발사 위치·패턴과 다리 위 불꽃을 큐(cue) 단위로 설계합니다.

주소: https://jihye84.github.io/firework/

## 쓰는 법
1. 왼쪽 **음악** 칸에 유튜브 주소를 붙여 넣고 ‘불러오기’ (검색어를 넣으면 유튜브 검색 창이 열려요).
2. 오른쪽에서 불꽃 모양·색·크기·패턴을 고른 뒤,
   음악을 재생하면서 박자에 맞춰 **탭!**(Enter)을 누르면 그 순간에 불꽃이 터지도록 큐가 들어갑니다.
3. 아래 타임라인에서 점을 눌러 고치고, 끌어서 시각을 옮기고, Del로 지웁니다.
4. ▶ 재생하면 상승 시간을 계산해 미리 쏘아 올리므로 **터지는 순간이 박자에 맞습니다.**

## 제어 항목
| 분류 | 항목 |
|---|---|
| 시간 | 터지는 시각(박자 맞춤: BPM·첫 박·1/½/¼박), 연발 간격, 다리 연출 길이 |
| 발사 자리 | 하늘(강 위 바지선) / 다리 위, 가로 위치, 구간, 데칼코마니(좌우 대칭) |
| 모양 | 국화·모란·버들·야자·링·토성·겹꽃·갈래·하트·별·네모·왕관·웃음·글자·반짝(스트로브)·타닥(크래클) |
| 크기 | 3·5·7·10·12호(인치) — 클수록 높이 올라가고 넓게 퍼짐 |
| 색 | 주색 11가지(무지개 포함) + 터진 뒤 바뀌는 색 |
| 꼬리·효과 | 상승 꼬리, 반짝이 꼬리 |
| 패턴 | 한 발 / 연발(차례로) / 동시(일제) / 부채꼴 |
| 다리 위 | 나이아가라(폭포), 파도 쏘기, 분수, 반짝 조명 + 번지는 방향(왼→오, 오→왼, 중앙→밖, 밖→중앙, 한꺼번에) |
| 보기 | 터지는 소리, 물 반사, 연기 |

## 저장
- 브라우저에 자동 저장됩니다.
- ‘파일로 저장 / 파일 열기’(JSON), ‘링크 복사’(쇼 전체가 주소에 담김)로 나눌 수 있습니다.

## 참고·출처
- 연출 아이디어: 한화와 함께하는 서울세계불꽃축제 2025 보도 자료와 기사
  (원효대교 중심 데칼코마니 연출, ‘네모의 꿈’ 사각 불꽃, ‘Golden’ 왕관 불꽃, 원효대교 나이아가라 등).
- 음악은 유튜브 IFrame Player로 재생하며 파일로 내려받지 않습니다.
  영상 주인이 외부 재생을 막아 둔 영상은 재생되지 않습니다.
- 그림·불꽃은 모두 코드로 그렸습니다. 외부 라이브러리 없음.
